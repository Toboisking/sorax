---
title: "Commands"
description: "Reference for the sorax command line."
---

Every command accepts `--help` for its full flag list, for example `sorax run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ sorax run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: SORAX review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @sorax/cli
      - run: sorax run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ sorax run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ sorax run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ sorax run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ sorax run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ sorax run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ sorax run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ sorax run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ sorax run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ sorax mini
```

Continue the last session.

```bash
$ sorax mini --continue
```

Start with a model and an initial prompt.

```bash
$ sorax mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ sorax mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ sorax mini --help
```

## session

Manages sessions.

```bash
$ sorax session list
```

Limit the list and print JSON.

```bash
$ sorax session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ sorax session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ sorax session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ sorax session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ sorax session import session.json
```

Import into a specific directory.

```bash
$ sorax session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ sorax session --help
```

## auth

Manages AI providers and credentials.

```bash
$ sorax auth list
```

List them as JSON.

```bash
$ sorax auth list --format json
```

Log in to a provider.

```bash
$ sorax auth login anthropic
```

Log in with a specific authentication method.

```bash
$ sorax auth login anthropic --method key
```

Log out of a saved account.

```bash
$ sorax auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ sorax auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ sorax auth export anthropic > credentials.json
$ sorax auth import credentials.json
```

View all subcommands and flags.

```bash
$ sorax auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ sorax mcp list
```

Add a remote server.

```bash
$ sorax mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ sorax mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ sorax mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ sorax mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ sorax mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ sorax mcp logout sentry
```

View all subcommands and flags.

```bash
$ sorax mcp --help
```

```bash

```

```bash

```

Install a plugin and add it to the global configuration.

```bash

```

```bash
$ sorax plugin check
```

```bash
$ sorax plugin update
```

Remove a plugin from global configuration.

```bash
$ sorax plugin remove @example/sorax-tui
```

View all subcommands and flags.

```bash
$ sorax plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ sorax serve
```

Bind to all interfaces on a fixed port.

```bash
$ sorax serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ sorax serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ sorax serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ sorax pair
```

Use an external URL in the links.

```bash
$ sorax pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ sorax pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ sorax pair --remote --yes
```

View all subcommands and flags.

```bash
$ sorax pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ sorax service start
```

Restart it.

```bash
$ sorax service restart
```

Show its status.

```bash
$ sorax service status
```

Stop it.

```bash
$ sorax service stop
```

Read a setting.

```bash
$ sorax service get hostname
```

Set a setting.

```bash
$ sorax service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ sorax service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ sorax service set env SORAX_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ sorax service unset hostname
```

View all subcommands and flags.

```bash
$ sorax service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ sorax reload
```

## api

Makes a request to the running server.

```bash
$ sorax api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ sorax api session.list --param limit=10
```

Send a JSON body.

```bash
$ sorax api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ sorax api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ sorax api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ sorax debug agents
```

List configuration sources.

```bash
$ sorax debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ sorax debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ sorax debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ sorax debug paths
```

Print a single path.

```bash
$ sorax debug paths db
```

View all subcommands and flags.

```bash
$ sorax debug --help
```

## upgrade

Upgrades SORAX to the latest or a specific version. Alias: `update`.

```bash
$ sorax upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ sorax upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ sorax upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls SORAX. Session data, configuration, and
state are not removed.

```bash
$ sorax uninstall
```

Preview what would be removed.

```bash
$ sorax uninstall --dry-run
```

View all subcommands and flags.

```bash
$ sorax uninstall --help
```
