### Kurulum

```bash
# YOLO
curl -fsSL https://sorax.ai/v2/install | bash

# Paket yöneticileri
npm i -g @sorax/cli@latest      # veya bun/pnpm/yarn
brew install anomalyco/tap/sorax-v2 # macOS ve Linux (önerilir, her zaman güncel)
brew install sorax              # macOS ve Linux (resmi brew formülü, daha az güncellenir)
sudo pacman -S sorax            # Arch Linux (Stable)
paru -S sorax-beta              # Arch Linux (Latest from AUR)
mise use -g sorax               # Tüm işletim sistemleri
nix run github:anomalyco/sorax  # Nix
```

> [!TIP]
> Kurulumdan önce 0.1.x'ten eski sürümleri kaldırın.

### Masaüstü Uygulaması (BETA)

SORAX ayrıca masaüstü uygulaması olarak da mevcuttur. [sorax.ai/download](https://sorax.ai/download) adresinden indirebilirsiniz.

| Platform              | İndirme                            |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `sorax-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `sorax-desktop-mac-x64.dmg`     |
| Windows               | `sorax-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm` veya AppImage       |

```bash
# macOS (Homebrew)
brew install --cask sorax-desktop
```

#### Kurulum Dizini (Installation Directory)

Kurulum betiği, SORAX'u `$HOME/.sorax/bin` dizinine kurar.

### Ajanlar

SORAX, `Tab` tuşuyla aralarında geçiş yapabileceğiniz iki yerleşik (built-in) ajan içerir.

- **build** - Varsayılan, geliştirme çalışmaları için tam erişimli ajan
- **plan** - Analiz ve kod keşfi için salt okunur ajan
  - Varsayılan olarak dosya düzenlemelerini reddeder
  - Bash komutlarını çalıştırmadan önce izin ister
  - Tanımadığınız kod tabanlarını keşfetmek veya değişiklikleri planlamak için ideal

Ayrıca, karmaşık aramalar ve çok adımlı görevler için bir **genel** alt ajan bulunmaktadır.
Bu dahili olarak kullanılır ve mesajlarda `@general` ile çağrılabilir.

[Ajanlar](https://sorax.ai/v2/docs/agents) hakkında daha fazla bilgi edinin.
