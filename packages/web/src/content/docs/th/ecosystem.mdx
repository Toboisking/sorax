ชุดโครงการชุมชนที่สร้างขึ้นบน SORAX

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ SORAX ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-sorax](https://github.com/awesome-sorax/awesome-sorax) และ [sorax.cafe](https://sorax.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
